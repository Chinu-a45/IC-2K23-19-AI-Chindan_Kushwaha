# Git workflow

The project is ready to initialize and commit locally:

```bash
git init
git add .
git commit -m "Add complete AI laboratory portfolio"
git branch -M main
```

To publish it, create a GitHub repository named `Chindan-Kushwaha-AI-Lab`
under your GitHub account, then add that repository's actual URL as `origin`
and push `main`. A remote cannot be preconfigured because the GitHub account
and remote repository URL were not provided.

Use meaningful commits for subsequent experiments and tag the final milestone:

```bash
git tag -a final-submission -m "AI Lab final submission"
```
