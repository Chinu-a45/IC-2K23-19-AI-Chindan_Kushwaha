# Lab 3 — AI Programming Frameworks and Data Preparation

**Aim:** Practice NumPy/Pandas data handling, EDA, cleaning, missing-value
handling, encoding, feature engineering, train/test splitting and visualization.

**Algorithm:** Load the placement CSV; inspect types/statistics/missing values;
remove duplicate rows; impute numeric and categorical values; encode categories;
create a CGPA band feature; split features and target; plot histograms and
correlation heatmap.

**Run:** `python Lab3/data_preprocessing.py`.

**Results:** The script prints dataset inspection and split dimensions and saves
`outputs/feature_histograms.png` and `outputs/correlation_heatmap.png`.

**Performance analysis:** This unit evaluates preprocessing quality and
reproducibility, not classifier accuracy. Compare row counts, missing-value
counts and feature dimensions before/after transformations.

**Learning outcomes:** Data loading, cleaning, transformation, encoding,
feature engineering and exploratory visualization.
